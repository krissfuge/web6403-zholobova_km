## Лабораторная работа №2

Книга рецептов.

### Страницы

- `index.html` — обложка книги.
- `contents.html` — содержание (ссылки на рецепты).
- `recipe1.html` — рецепт торта.
- `recipe2.html` — заготовка под следующий рецепт.

### Что реализовано

**HTML:**
- Блочные элементы: `div`, `p`, `h1`, `h2`, `ol`, `table`.
- Строчные элементы: `a`, `strong`.
- Ссылки — переходы между страницами.
- Картинка — `images/cake.png`.
- Таблица — ингредиенты.

**CSS:**
- Отдельный файл `css/style.css`.
- Три вида селекторов: по тегу (`body`, `table`), по классу (`.book`, `.page`), по ID (`#main-cover`).
- Использование цвета: палитра `#607456`, `#eee0cc`, `#ba6a4c`, `#7b2525`.
- Разное выравнивание в таблице: по левому краю (`.left-align`), по центру (`.center-align`).

**Оформление:**
- Сайт выглядит как книга: обложка + разворот из двух страниц.
- Перелистывание — по уголкам страниц.
