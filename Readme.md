## Лабораторная работа №2

Книга рецептов.

### Страницы

- `index.html` — обложка книги.
- `contents.html` — содержание (ссылки на рецепты).
- `recipe1.html` — рецепт торта.
- `recipe2.html` — заготовка под следующий рецепт.

### Что реализовано

**HTML:**
- Блочные элементы: `div`, `p`, `h1`, `h2`, `ol`, `table`.
- Строчные элементы: `a`, `strong`.
- Ссылки — переходы между страницами.
- Картинка — `images/cake.png`.
- Таблица — ингредиенты.

**CSS:**
- Отдельный файл `css/style.css`.
- Три вида селекторов: по тегу (`body`, `table`), по классу (`.book`, `.page`), по ID (`#main-cover`).
- Использование цвета: палитра `#607456`, `#eee0cc`, `#ba6a4c`, `#7b2525`.
- Разное выравнивание в таблице: по левому краю (`.left-align`), по центру (`.center-align`).

**Оформление:**
- Сайт выглядит как книга: обложка + разворот из двух страниц.
- Перелистывание — по уголкам страниц.

# Лабораторная работа №4

Книга рецептов.

### Что реализовано

#### HTML
- Таблица ингредиентов с третьим столбцом-чек-листом (`checkbox`).
- Форма заметки: `input` (имя), `textarea` (текст), `checkbox` (галочка) + кнопка «Отправить».

#### CSS
- Все цвета — **только через переменные** в `:root`, во всём файле используются `var(...)`.
- Вёрстка **Flexbox** — разворот книги `.book`, ряд «фото + таблица» `.recipe__top`, колонка «доска + кнопка» `.note-form`.
- Вёрстка **Grid** — обложка `.cover` на странице `index.html`.
- Анимация — `@keyframes pulse` на кнопке «Отправить».

#### JavaScript
- Отдельный файл `js/script.js`, подключён к `recipe1.html`.
- Класс `RecipeNote` с конструктором (`name`, `text`, `agree`) и методом `printToConsole()`.
- По нажатию кнопки «Отправить» создаётся объект, вызывается метод (вывод в консоль), текст заметки добавляется в список заметок на странице, форма очищается.

#### Методология БЭМ
- Все классы построены по схеме `block__element--modifier`:
  `book`, `page page--left`, `recipe__top`, `recipe__photo`,
  `recipe-table__head--center`, `corner--right`,
  `notes__item`, `note-form__board`, `note-form__button` и т.д.
